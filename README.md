
# NEXA AI — Studio 🤖🚀

NEXA AI is a next-generation multimodal AI platform built with Vite and TypeScript, designed for intelligent chat, research, document analysis, coding, data analysis, AI agents, knowledge management, and productivity.

🌐 **Live Demo:** [https://vercel.app](https://vercel.app)

---

## ✨ Features
* **Intelligent Chat & Research:** Advanced conversational AI for multi-purpose research.
* **Document Analysis:** Upload and analyze text, PDFs, and documents instantly.
* **Coding & Data Analysis:** Built-in capabilities to assist in development and data-driven insights.
* **AI Agents:** Deploy intelligent agents for task automation and knowledge management.

---

## 🛠️ Tech Stack & Languages
* **Frontend:** React / Vite
* **Language:** TypeScript (99.7%)
* **Deployment:** Vercel
* **CI/CD:** Deno / GitHub Actions
* **AI Engine:** Google AI Studio (Gemini Models)

## 🚀 Getting Started Locally

### Prerequisites
Make sure you have **Node.js** installed on your system.

### Installation & Setup Steps

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd nexa-ai-studio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Set up Environment Variables:**
   Create a `.env.local` file in the root directory (refer to `.env.example`) and add your Gemini API Key:
   ```env
   GEMINI_API_KEY=your_actual_api_key_here
   ```

4. **Run the development server:**
   ```bash
   npm run dev
   ```

## 📦 Deployment

This project is configured for seamless deployment on **Vercel** using the `vercel.json` configuration file. Any changes pushed to the `main` branch will automatically deploy to production.
